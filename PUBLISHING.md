# Publication checklist

Repository: `Paotaro/discourse-registration-enhancements`

Suggested description: A configurable Discourse theme component for registration layout, rules links, and field feedback.

Suggested topics: `discourse`, `discourse-theme-component`, `registration`, `community-management`, `i18n`.

After explicit publication approval:

1. Create an empty public repository under Paotaro. Initialize Git from this snapshot alone. Review commit identity and stage only files listed in `PUBLIC-FILES.txt`.
2. Push the reviewed commit to `main`. Create tag `v2.0.0` for that commit.
3. Draft a GitHub Release from the tag. Copy `RELEASE-NOTES.md` and attach the separately prepared component ZIP and checksum. GitHub's generated source archive is separate from the component ZIP.
4. Review the public tree, tag, license, links and attached bytes. Publish the release after approval. Verify installation from the published URL on an isolated Discourse instance.

[GitHub release instructions](https://docs.github.com/en/repositories/releasing-projects-on-github/managing-releases-in-a-repository)
